# trpc_flutter

Flutter bridge for trpc_dart - ValueListenable over cache-backed queries.

Part of the [rpc-dart](https://github.com/rpc-dart/rpc-dart) monorepo — end-to-end type safety for tRPC v11 backends consumed from Dart and Flutter.

## Install

```yaml
dependencies:
  trpc_flutter: ^0.1.0
```

See the [documentation](../../docs/README.md) and `example/main.dart` for usage.
